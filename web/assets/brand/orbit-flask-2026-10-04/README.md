# 大师实验室标识：轨道烧瓶（正式版）

确定日期：2026-10-04。正式启用，已替换网页的 favicon 和页首标志。

设计来源：烧瓶主体沿用自制稿（描边烧瓶、浅蓝液体、两个气泡）；环沿用自制结合稿的浅色渐细椭圆环，仅上移避开液面、整体收窄 6%，使液体和气泡完整、烧瓶在图标中更大。全部为矢量重绘，可任意缩放。

## 配色

- 瓶身描边 `#2d73f6`
- 液体 `#74b1fc`，环 `#74adfb`
- 瓶内与气泡 `#ffffff`
- 图标底色 `#f7f9fd`

## 文件

| 文件 | 用途 |
|---|---|
| `logo.svg` | 完整标志，透明底。64px 以上使用（海报、PPT、页面大图） |
| `logo-small.svg` | 加粗简化版（去气泡），透明底。24–48px 使用，页首标志用的就是它 |
| `logo-16.svg` | 仅烧瓶、不带环的加粗版。16px 专用，带环在 16px 会糊 |
| `app-icon.svg` | APP 图标矢量母版，满版方形 + 底色，圆角交给系统裁切 |
| `app-icon-1024.png` | APP 图标主图（应用商店、鸿蒙 AppScope 等），不透明 |
| `icon-192.png`、`icon-512.png` | 网页安装到桌面时的图标（manifest） |
| `app-icon-maskable.svg`、`icon-maskable-512.png` | Android 自适应图标，标志完整落在中心 80% 安全圆内 |
| `apple-touch-icon.png` | iOS 添加到主屏幕，180 × 180 |
| `favicon-16/32/48.png`、`favicon.ico` | 浏览器标签图标；ICO 中 16px 为纯烧瓶，32/48px 带环 |

`web/favicon.ico` 是本目录 `favicon.ico` 的副本，放在网站根目录供浏览器默认请求。

## 注意

根目录 `.gitignore` 忽略了所有 `*.png`，已为本目录单独加了例外规则，否则这些 PNG 不会被提交，线上会缺图。

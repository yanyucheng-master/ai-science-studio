## 本轮内容

- 照片识题：拍照、文件选择、格式校验与压缩、识别反馈和取消。只将转写填入输入框，由用户核对后生成实验。配套公益网关使用独立的大小、频率与并发限制；真实照片准确率尚未验收。
- 显微镜：总放大倍数、仅更换物镜时的视野比较、倒像与移片方向。视野近似细胞数保留小数；示意网格不表示真实细胞，移片坐标不表示实际长度。

- 界面：去掉导师内容中重复的“关键追问”前缀，精简电脑页首，调整生物公式结果行。
- 内部维护：新增显微镜、种群的单元与浏览器专项代码，题库由467条扩为560条并保留原条目；更新共享检查的模块清单。这些脚本本轮未执行。

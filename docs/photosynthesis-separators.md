# 分隔方式、严格解析与路由归属（2026-11-06）

对应[本轮审查](https://github.com/yanyucheng-master/ai-science-studio/issues/9#issuecomment-6677984038)。旧候选另写了要求句首/标点边界的正则，而科学解析已经接受空格、顿号、无分隔等格式，确实导致可识别题目漏入自动回退。

## 共同依据和入口顺序

现在两个模板都提供同源的`protocolAssessment`。它复用科学解析的`sourceView`和同一组完整条件规则；条件规则仅增加实验目标、材料、教材说明、具体操作等路由元数据，不改变条件匹配、数值、学段、所问、模型或固定参数。

1. 规划入口先尝试两模板各自的完整严格解析，不再由候选布尔值挡住它。严格解析成功且唯一时直接生成，包括允许的条件分隔方式和列举顺序，以及原来允许的跨学科入口。
2. 失败时，用相同条件规则统计已经明确出现的完整条件片段。明确目标与教材/材料/操作组合，或多项具体教材操作，确定流程归属；原文仍严格失败，返回本地具体诊断，保留旧实验，不自动请求AI。识别到片段不能视为完整题成功，不会吞掉未知条件/子问。
3. 只有少量相关操作、或目标/材料加实验所问时，归属可能不确定。先尝试其它原有本地模板，已有成功优先；没有本地成功才提示归属不确定和具体待核部分，仍不自动发送。两套流程不能唯一判定时要求拆开说明，不按注册顺序挑第一条。
4. 没有这些完整条件证据的一般概念、背景词，继续原有识别/导师回退。主题关键词不参与强制改判学科。

这不是第二套宽松科学解析器：证据扫描只说明路由归属，不产生参数或结果。只有原本完整严格解析通过才能生成。未知片段、矛盾、数值角色、明确错误步骤及范围外子问继续拒绝。条件列举换序沿用原解析允许范围，不改变教材六步及句内明确的先后关系。

## 分隔、引用和数值

路由视图不再删除空格后要求另一个标点锚点。它保留分隔和数值内部空白，交给科学解析共用的规范化机制处理；`3 0`、`3,0`不能被拼成30。数字/单位的现有精度与范围未放宽。

嵌入引号的背景用不可拼接的标记遮蔽，避免跨背景拼出完整操作。整道引号题或明确请求包裹题仍可以进入本地核验，但科学解析始终看未经路由改写的原文，不靠去引号接受不支持的句子。

`protocolCandidate`保留为兼容布尔API，由同源assessment派生；完整严格解析接受时必为true。它对不确定片段也可能为true，不能当作自动抢占其它已成功模板的理由，实际入口按上述顺序处理。

## 验证和范围

`photosynthesis-separator-cases.json`保存两份逐字标准题条件，实施前封存80项分隔/条件列举顺序变换及独立正反例预期。它们是格式/顺序的变形检查，不冒称外部盲测或新增科学题型。真实标准题与静态字词核对一致；API接受/拒绝、候选/归属与真实按钮结果分别报告。

正常按钮覆盖逗号、空格、顿号、无分隔、混合换行/标点的完整题、缺项、冲突、错误操作、额外子问、缺所问，以及问句前置和条件列举换序；导师存在/缺失与模拟200/503、两种联用加载顺序分开记录。另核对少量操作的归属澄清、已有平面镜优先、上轮普通问答/引用背景/光照背景反例。

新矩阵四个场景对导师状态、模拟服务状态和加载顺序做成对组合，不声称所有维度的完全笛卡尔积。完整题/非法题都不应有自动请求，服务200/503仅用于揭示意外回退，不能算真实AI验证。

本轮只涉及既有J02/H11部分样例。预测、学生记录、比较和解释控件仍未实现，记录生命周期/刷新/重置/收藏分享仍待协调；不扩展share-v1或其他实验族，不代表P0/20族完成。PR保持Draft，不合并、不推master/公网、不部署，旧自动化不恢复。

## 六、各实验范围

### 并联电路（物理 · 初中 · 电学，小）
- 能接：两个电阻并联接在电源上，求干路电流、支路电流、总电阻
- 转 AI：三个及以上电阻、混联、含滑动变阻器或灯泡、“如图”
- 滑块：R₁、R₂；电源电压从题目读取
- 图示：并联电路图，支路电流用箭头粗细或粒子密度表示，电流表读数 I、I₁、I₂
- 例：R1=6Ω 和 R2=3Ω 并联接在 6V 电源上，求干路电流 → 3A

### 平面镜成像（物理 · 初中 · 光学，小）
- 能接：像到镜面的距离、像与物的距离、像高
- 转 AI：移动速度、镜面转动、两面镜子、“至少需要多长的镜子”
- 滑块：物距 u、物高 h
- 图示：镜面、物体与虚线虚像、对称连线和刻度；标注“虚像，光屏上接收不到”
- 例：物体距镜面 20cm，像距镜面多远？→ 20cm

### 化学定量反应引擎（化学 · 初中 / 高中，大）
- 反应表首批：CaCO₃ + 2HCl = CaCl₂ + H₂O + CO₂↑；Zn + H₂SO₄ = ZnSO₄ + H₂↑；2H₂O₂ =(MnO₂)= 2H₂O + O₂↑
- 讲法：初中按相对分子质量的质量比列比例式；高中按物质的量
- 能接：已知一种物质的质量（反应物或生成物），另一反应物“足量”，求其他物质的质量；两种反应物都给出时判断哪种过量
- 转 AI：纯度、溶质质量分数、质量差法、多步反应、表外反应
- 滑块：已知物质的质量；另一反应物的量（题目写“足量”时锁定）
- 图示：锥形瓶 + 电子天平，气泡随反应物减少变慢，放出气体后示数下降（质量守恒）
- 例：10g 碳酸钙与足量稀盐酸 → CO₂ 4.4g；6.5g 锌与足量稀硫酸 → H₂ 0.2g；3.4g 过氧化氢完全分解 → O₂ 1.6g

### 二次函数图像与性质（数学 · 初中 / 高中，小）
- 能接：y = ax² + bx + c 的顶点、对称轴、开口、最值、与坐标轴交点
- 分流：含“切线、斜率、导数”走切线模板
- 转 AI：含参数讨论、区间最值、反求解析式
- 滑块：b、c；拖 c 看 Δ 变号、交点出现或消失
- 例：y = x² − 4x + 3 → 顶点 (2, −1)，与 x 轴交于 (1, 0)、(3, 0)

### 方程组 = 两直线交点（数学 · 初中，中）
- 能接：两个二元一次方程，整数或简单小数系数；识别无解（平行）、无数解（重合）
- 转 AI：三元、含参数、需要先列方程的应用题
- 滑块：常数项 c₁、c₂
- 例：2x + y = 5，x − y = 1 → x = 2，y = 1

### 孟德尔分离定律（生物 · 初中 / 高中，中）
- 能接：一对相对性状、完全显性，亲本 AA / Aa / aa 组合；后代基因型比、表现型比、某性状概率
- 转 AI：两对相对性状、伴性遗传、不完全显性、致死、系谱图、“如图”
- 参数：亲本组合（从题目读，可切换）+ 后代数量 n（10–1000）
- 图示：配子与棋盘格；抽样统计柱状图对照理论比例
- 讲法：初中八年级下册（基因的显性与隐性）；高中必修 2（分离定律、假说—演绎）
- 例：Aa × Aa → 表现型 3∶1，基因型 1∶2∶1

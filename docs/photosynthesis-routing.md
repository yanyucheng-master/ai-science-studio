# 固定教材流程候选与普通路由（2026-11-06）

回应[本轮路由退回](https://github.com/yanyucheng-master/ai-science-studio/issues/9#issuecomment-6663761843)。此前将宽泛关键词强制判为生物，确实影响了其他学科本地成功及正常导师回退。两个独立PR和联用均有各自真实按钮复现，不以联用证据代替单支。

## 候选不是识别成功

两个模板的`protocolCandidate`只判断是否有明确的固定实验语境，不决定科学结果，也不把缺条件变成已知条件。它与用于菜单/检索的`keywords`、用于失败归属的`diagnosticPriority`分开。

- 初中：句首或条件分隔处的天竺葵暗处理、同叶黑纸遮光等材料—动作组合；或“探究绿叶在光下制造有机物”明确目标，同时有相应人教教材定位或水浴/滴碘操作。单独“光合作用”、材料名、展区或引号内背景标题、仅讨论研究意义均不够。
- 高中：打孔器制备叶圆片、每杯投入叶圆片等器材/对象—动作组合；或“探究光照强度对光合作用强度的影响”明确目标，同时有人教必修1定位或旺盛菠菜绿叶取材。单独光照强度、光合作用强度、叶圆片定义或仅讨论研究意义均不够。

候选只用有限、可解释的语序/词法，不宣称理解任意自然语言。无法据实验语境确认属于本固定流程的普通题，保留原有本地规划和正常回退；已明确进入流程的题则必须完整核对。

## 入口顺序和保持的边界

1. 原有条件检查不变。仅对明确流程候选做独立预检，允许书名省略、从其他学科或学段入口打开完整教材题。
2. 候选仍调用原严格解析器核对全题、角色、数值、操作与全部子问。成功才生成相应生物实验；失败按已限定的实验关联选择诊断，保留原题/实验/位置，不自动发AI。
3. 真正同时要求两种实验、或教材流程夹带其他科学子问时，不能因另一模板能理解其中一部分就忽略教材条件；严格解析继续拒绝混合题，不补条件或吞子问。
4. 不属于候选时，保留原`detectSubjectStrict`、选择学科和原模板流程。常规生物循环不会再用两模板的宽泛关键词收集localOnly失败。普通光合作用问答和普通物理灯光题可走原有导师回退；测试只允许本地模拟请求。

科学流程、教材正文映射、固定参数、没有实测数据的边界、共享纯文本提示、六步播放器和share-v1协议未改。预测/学生记录/比较解释控件仍未实现，见[待审方案](photosynthesis-interaction-proposal.md)；本轮不自行决定刷新、重置、收藏分享是否携带学习记录。

## 验证口径

`server/eval/photosynthesis-routing-cases.json`包含独立题目和路由预期。首28例在实现前封存，另两例“仅讨论相近研究目标的意义”单列为边界补充；不称外部盲测。Node候选断言与真实页面证据分开：前者不能替代普通按钮、请求或状态检查。

新浏览器专项使用正常按钮，隔离浏览器和本地模拟，记录选择学科/学段、实际识别、请求、旧实验与位置。覆盖两模板加载顺序、导师存在/缺失、完整/缺失/矛盾/错步骤/附加子问、其他学科成功/回退、模拟503和模拟成功。初中和高中独立PR只测试该分支实际包含的教材模板，联用两者都测；未加载的模板不伪称生成通过。

## 教材与实现逐项对应

| 正文定位 | 保留的实验内容 | 网页呈现 |
| --- | --- | --- |
| p29，目的与材料 | 检验淀粉、探究光照条件；盆栽天竺葵，黑纸片/曲别针，酒精，水，小烧杯，水浴锅，培养皿，碘液，镊子 | 器材清单与六步流程均可查看，图形原创，不复制教材照片 |
| p29，步骤1 | 整株暗置一昼夜 | 暗处的天竺葵；解释消除叶片原有淀粉的干扰 |
| p29，步骤2 | 同一叶片的一部分上下两面遮光，再接受阳光 | 双面黑纸/曲别针与同叶见光区形成对照，不改成两株植物 |
| p29，步骤3 | 几小时后取叶，撤去纸片 | 镊子取叶、黑纸移出；叶仍绿色，不能提前呈现碘液反应 |
| p29–30，步骤4 | 酒精中的叶片在水浴锅中脱色 | 水浴锅内的小烧杯；叶由绿转黄白，酒精呈绿色示意。保留酒精易燃、只能水浴的教材注意事项，不画直接火焰 |
| p30，步骤5 | 清水漂洗，移到培养皿，再滴碘液 | 同一步内分先后呈现漂洗与滴加，不能漏掉漂洗 |
| p30，步骤6与讨论 | 稍停、冲去碘液后观察；原见光区蓝色，原遮光区不变蓝 | 先停留/冲洗，再展示同一叶片两个区域；分别解释淀粉与光照条件 |

只能由该对照支持“光是制造淀粉的必要条件、淀粉是产物”的教材结论，不声称一次实验独立证明二氧化碳原料、氧气释放、叶绿体场所或测出光合速率。教材的进一步切片/显微观察与剪影活动不并入首版。

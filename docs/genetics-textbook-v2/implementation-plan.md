## 完整组合范围

- 常染色体单个位点：3个基因型×3个基因型＝9个有序亲本格。AD、AR用同一配子结果、不同表型映射。
- 伴X位点：女方3×男方2＝6格。XR、XD用同一遗传结构、不同符号和表型映射；不交换父母性别槽。
- 两对独立常染色体：9个个体基因型×9＝81格。教材豌豆Y/y、R/r，符号练习可用A/a、B/b；未声明独立时不给自由组合结果。
- 常染色体＋伴X：女方3×3＝9种；男方3×2＝6种，共54格；支持XX/XY的合并书写。
- 总计**150种结构组合**（9＋6＋81＋54）。若AD/AR、XR/XD分别核对表型，是**165次模式演算**（18＋12＋81＋54），不是165种独立结构。

离线手算校核以显式9格单基因表、6格XR表和独立乘法准备预期；产品将用配子生成、受精组合、规范化合并的通用纯函数，双方不共用“由被测结果产生预期”的代码。概率保留整数分子/分母，显示约分后分数；性别条件先限定分母，概率为0的条件不能做除法。

全部数值是题设模型的理论概率。教材页图、家系约束、通用计算、模拟示意分开，首版不增加随机出生动画或虚构实测频数。

## 页面与状态设计

1. 入口拟放“高中→生物→遗传”，与现有孟德尔并列。主界面六模块优先经典例；“更多亲本组合”面板再覆盖全部合法组合。只复用现有外壳和统一手动步骤，不增加第二套播放器。
2. 四步固定为“读图找关系→推基因型→列配子→回答/算出所问”。家系选择、当前成员信息、步骤和右侧解题路径同源。原问与变式分开，修改所问会同步题面及导师上下文。
   正式练习将允许先选亲本/配子或填预测，再展开核对；改变合法亲本后比较哪些结果改变，给出相应亲子约束与计算解释。本轮预览仅有点选和分步核对，尚无学生作答控件，不宣称这部分练习闭环已完成。
3. 方/圆固定大小，患病填充不随选中改变。携带标记只在有题给或推导依据时出现，独立于编号；表型未知不画成“正常”。双病分别用纹理和实点；每个节点≥44px点击区及键盘可见焦点。20人家系在窄屏内部横向平移，页面本身不横向溢出。
4. 原题、当前组合、重置初始配置分开。切换样题应原子更新canonical题面、基因型/条件和所问，再允许收藏或复制；当前参数比较不悄悄改写原题。重置回生成时的题目配置，清除成员选择与临时推导进度。
5. 收藏/分享仍走现有机制，不扩展后端或分享协议。题面保持简洁自然且不超过收藏1200字符截断阈值；版本、校验信息放白名单固定配置，不要求学生逐字写出。恢复严格校验模板、模块、成员关系、条件、性别、基因型和所问；未知版本、本轮未支持题型、混合子问本地拒绝并保留旧实验。若现有分享白名单无法无歧义恢复，先如实交阻塞，不绕过校验。
6. 从初中打开高中收藏/分享，按题面和固定配置恢复高中内容，不能只改徽标。切样例后立即收藏/复制、独立浏览器导入、刷新、A→B→A、真实BFCache等均在实施后验证。预览没有这些功能，不拿点击原型结果充当恢复证据。
7. 本地失败只展示纯文本、明确缺项与所在成员/位点；当前图和步骤保留。导师仅见新题及缺口，不携带旧答案；固定教材流程失败自动AI请求为0。普通概念、旧孟德尔及其他学科路由保持；背景文字不劫持实际题目，多项真实所问不吞掉。
8. “AaAa”必须先区分两亲本Aa×Aa与同个体两位点AaBb；“XYAa”缺X上B/b须澄清。支持受检的上标/常见空格和乘号等价写法，统一到有位点、有亲本角色的结构；不执行任意表达式。

## 测试与证据计划

独立预期见题面手算；特别保留1/4、2/3、1/2与1/4条件差异、联合六型及9/16等值。每项功能证据绑定最终运行源码SHA/树，运行后改实现按影响复测，不将文档追加SHA冒称完整运行SHA。

1. **模型**：150结构逐格、165表型模式，概率总和1、父母各供一个对应位点等位基因、父给女儿X/儿子Y、纯合退化、交换常染色体双亲不变、条件概率分母、两位点边缘分布等于单个位点。六图数据与人工表一致。
2. **语义与题库**：原问/变式、条件前后顺序、标点/空白、成员编号、数字角色、未知携带、重复/矛盾、非法基因型/亲本性别、不支持附加子问；Aa×Aa/AaBb/XY合并格式。题目背景与实际所问分开，正常教材题可跨入口；真正混合任务本地澄清。
3. **真实按钮**：生成成功/拒绝，保持旧图、步骤与播放状态；新题导师不借旧答案。导师存在/缺失、模拟服务成功/失败分别记请求数和文案，固定失败0自动AI。普通概念回退只接本机模拟服务。
4. **状态闭环**：经典题与组合面板切换、选择、双向步骤/统一控件、重置、学科/学段往返；切图立即收藏/分享、初中开高中收藏、独立会话、刷新、A→B→A和实际BFCache。逐项核对原题、当前组合、所问、固定前提和重置基准。
5. **布局**：360/390/820/1366、844×390、全屏与滚动；深浅/纹理图例、连线端点、代际/编号、携带标记分位、上标/分数，≥44px点击区、键盘全部成员、选中前后几何与填充不变；截图和几何/DOM断言同时保留。
6. **适用全回归**：按实施时基线重新枚举，不只跑新模块。包含Node、题库、既有孟德尔、share、学段/菜单/收藏、tutor、animation、announcements、formula、ai-quality、tutor-presentation、当前斜面含`--data`、instant/instant-routing/tutor-diagram、拍题、显微镜、种群、光合作用、化学、数学及其他适用入口。保留原CI/安全/签名检查。旧斜面guard、种群后台等如再现，候选与干净同基线分别跑并列原始失败和未到达断言，不以相同签名当作根因已明或通过。
7. **环境**：只用本地服务器、隔离配置、模拟响应。Firefox/Safari、真机、真实AI、CI/扫描、部署分别报告实际状态；未执行明写，空GitHub记录不算通过。

### 摩擦初中讲法

- 弹簧测力计沿水平方向匀速拉动木块；压力 2–30N，接触面按教材用木板、棉布、毛巾。测力计示数为模拟值，用来比较大小，界面标“模拟”；按二力平衡 f = F拉，不出现动摩擦因数 μ。
- 接触面积、速度快慢、拉动方向、重力、质量等教材结论为“无关”或超出本实验的因素不套用本模板，转 AI。题目给出 μ 或要求计算摩擦力时按高中讲法。

### 二次函数图像与性质（2.4）

- 只接一般式 y = ax² + bx + c 或 f(x) = ax² + bx + c（a ≠ 0，各项不重复）；a 取自题目（|a| ≤ 10），滑块调 b、c（−10 到 10；题目给出的数值在 −20 到 20 之间），系数最多两位小数。
- 初中讲开口方向、配方求顶点与对称轴、增减性和与坐标轴的交点；高中讲单调区间、最值、值域与零点。题目没有学段线索时跟随所选学段。
- 按有理数精确计算：整数系数的结果写成分数，无理根写成根式并附近似值，Δ = 0 时写“与 x 轴只有一个交点（顶点在 x 轴上）”。变式让 Δ = 0（顶点落在 x 轴上）。
- 转 AI：区间最值、含参数、反求解析式、平移、对称点、与直线的交点、函数值、不等式、应用题、题图；涉及切线、斜率、导数的题走切线模板。

### 二元一次方程组与两直线交点（2.5）

- 两个二元一次方程（含 y = kx + b 和竖直线 x = a），未知数系数绝对值不超过 10、最多两位小数；滑块调两个常数项 c₁、c₂（−10 到 10；题目数值在 −20 到 20 之间）。
- 加减消元步骤（乘数约分后写成“① + ②”等形式）与两直线交点图同步；能识别无解（两直线平行）和无数组解（两直线重合，第二条直线画成虚线）。
- 转 AI：三元或三个以上方程、含参数、应用题、乘积或乘方项、另求代数式（如 x + y 的值）、面积 / 距离 / 斜率 / 截距、题图。

### 铁 + 硫酸铜初中讲法（3.2 提前，含“足量”）

- `web/chemistry-extra.js`：相对原子质量取初中教材附录的取整值；`relativeMass` 计算相对分子质量，`proportion` 按教材步骤写出“设、写方程式、找相关量、列比例式、求解、答”。
- 初中按质量比 56∶160∶64；铁 2.8–16.8g、硫酸铜 8–48g。两种反应物都给出质量时先判断哪种过量；题目写明“足量”时，足量一方的滑块锁定，并按普通问答发送 AI 请求。例：5.6g 铁与足量硫酸铜溶液反应，56/64 = 5.6g/x，x = 6.4g。
- 高中原有题型（铁的质量 + 硫酸铜的物质的量）文字不变，另加高中“足量”讲法。题目含物质的量时锁定高中讲法，只给质量时跟随所选学段。
- 转 AI：题目给出的相对原子质量与模板不一致（如 Cu 取 63.5）、既给出用量又写“足量”、超出演示范围。

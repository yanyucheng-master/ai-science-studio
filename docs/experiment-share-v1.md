# Web 实验分享 share-v1

本轮面向 `master` 的实现范围：自包含实验配置链接、本地确定性恢复、旧学科链接兼容及失败提示。没有部署到公网，也没有改 AI 协议、模型配置或鸿蒙工程。

## 格式与边界

链接为 `origin + pathname + #/share/<payload>`，从 HTTP(S) 页面创建。payload 是 UTF-8 JSON 的无填充 base64url；它是编码，不是加密。分享链接只用当前 origin 和 pathname 重新构造，不保留 URL 用户凭据、任何查询参数或旧 fragment，不累积片段，不携带服务配置、密钥、收藏、聊天或内部快照。

顶层字段严格白名单，全部必填；未知字段、缺失字段、类型错误直接拒绝：

| 字段 | v1 含义与校验 |
| --- | --- |
| `v` | 数字 `1`；未知版本拒绝 |
| `subject` | `物理`、`化学`、`数学`、`生物` 之一 |
| `question` | 当前已生成实验的题目，非空、无首尾空白，最多 2000 个 UTF-16 代码单元；按纯文本显示 |
| `grade` | `junior` 或 `senior`，表示分享时的全局所选学段 |
| `template` | 已登记通用模板 ID，或专用 ID：`brake`、`boardSlider`、`solenoid`、`projectile`、`circuit`、`chemistry`、`math`、`biology`；必须与学科及本地规划结果一致 |
| `params` | 两个有限数值，按页面两滑块顺序；细胞使用空数组，观察角度不分享、结构数量由模型重建 |
| `mode` | 下表的精确字段集合；没有模式的模板必须是空对象 |

| 模板 | `mode` 字段 |
| --- | --- |
| 刹车 | `braking`：本地解析所得 `constant`、`friction`、`linear_drag` |
| 螺线管 | `viewEnd`、`windingDirection`、`hasCore`，与题目解析所得观察端、电流绕向和铁芯状态逐一一致；观察端影响磁极命名，需要保留，不属于 3D 摄像机角度 |
| 化学、双学段通用模板、细胞 | `level`：实际讲法 `junior` / `senior`；`locked`：是否锁定本实验讲法的布尔值；未锁定时讲法必须与 `grade` 一致 |
| 其他模板 | `{}` |

JSON UTF-8 最多 8000 字节，对应实际生成的无填充 base64url 最长为 `ceil(8000 × 4 / 3) = 10667` 字符。接收端的 10668 字符仅为按有填充长度计算的外层粗筛阈值，不代表可接受 10668 字符的有效载荷；解码后始终再次检查最多 8000 字节，并检查规范编码。完整 URL 最多 12000 字符，题目最多 2000 个 UTF-16 代码单元。发送与接收都有限制；base64url、UTF-8、JSON 损坏或非规范编码拒绝。上限不保证任何外部消息平台传递成功，不增加短链接后端。

题目描述的是生成时的条件，`params` 表示分享时的实验值，两者可以不同。模板、模式与固定条件必须一致。固定量（重力、质量、函数系数、原题所求量、是否足量、未给出的镜前物距/物高等）从既有严格解析器重建；发送时还核对实际固定条件，无法重建时明确拒绝。分享不是签名协议：合法修改为另一组有效实验参数可以被接受，格式错误或超出模型能力的数据会拒绝。

数值校验复用既有模板的 `strict.rangeFor`、`strict.caps`、参数定义、`strict.checkFixed` 和本地解析器；通用模板还对当前参数生成的题目做严格解析，核对机械效率等跨参数约束。专用模板的滑块范围由既有内容构造函数提供；匝数与离散选项须为整数、足量等锁定参数必须保持锁定值。没有另建计算引擎。

## 恢复顺序与路由

1. 在 `app.js` 完成普通首页初始化之后、AI 导师脚本初始化之前加载 `experiment-share.js`。读取分享 fragment，先校验编码、大小、结构、模式、学科、模板、题目与参数；校验期间不写页面实验状态。
2. 使用显式学科、模板与有效讲法调用 `planLocalExperiment`，不受接收者当前学科、模板或默认题影响。题目无法本地生成时拒绝，不请求 AI，不换成默认实验。
3. 保存接收者当前实验的本地学科快照；在本页采用链接 `grade`，不覆盖其持久化学段偏好，也不运行会改写其他实验的学段切换处理器。
4. 通过原有 `generateExperiment` 应用已验证的本地计划，跳过演示生成过场；按明确字段应用当前参数与必要讲法，复用原有内容与参数同步函数。URL 对象不会合并进完整状态。
5. 核对应用后的参数，更新目标学科快照；动画初始暂停，细胞不自动旋转，螺线管动画暂停。只在生成实际完成后显示恢复成功。非预期渲染失败时显示等待生成状态和纯文本原因，保留既有快照并允许手动生成。

`#/ai-tutor` 沿用原处理器。分享入口仅识别 `#/share/<payload>`；`#/share` 或空载荷会提示格式错误，`#/share-extra` 等其他路由不视为分享。载荷必须完整满足 base64url 字符与长度规则，不能附带路径或额外片段。

每份成功恢复的最小配置按规范字段顺序重新编码，在当前文档内记录为已导入；失败的配置不记作成功。相同状态即使以不同 JSON 字段顺序编码，或经过旧学科链接、其他分享状态、AI 页面再返回，也不重复导入、覆盖当前调整。`pageshow` 从往返缓存返回时保留文档的已导入记录与当前状态，不强制恢复旧参数；真正刷新产生新文档后才重新导入。普通首页不导入；旧的 `#物理`、`#化学`、`#数学`、`#生物`（含 URL 编码形式）仅选择学科并等待手动生成，明确提示旧链接未记录实验。

收藏与聊天的存储键不会写入或清空。只更新目标学科配置及必要的全局本页学段；其他学科快照保留。AI 页面继续使用既有上下文变更处理，不因导入自动发送请求。

2026-10-19 同步最新 `master` 基线后，保留其即时科学示意图与品牌动效。share-v1 仍仅支持原有可严格本地重建的实验；即时图示处于当前上下文时明确拒绝分享，避免把其保留在后台的旧实验误当成当前图示。未扩展即时图示分享或 AI 协议。

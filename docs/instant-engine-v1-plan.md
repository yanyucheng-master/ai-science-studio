## 最小方案

严格本地模板优先；未匹配时调用独立 DeepSeek 场景供应商，输出版本化 JSON；共享校验器在服务端和浏览器分别检查；客户端用受控 DOM API 绘制 SVG。失败或拒绘转入现有文字导师，不修改原实验参数与进度。

模型不能输出 SVG、HTML、脚本、属性字典或任意表达式代码。图元支持线、箭头、矩形、圆、椭圆、多边形、折线、圆弧、坐标轴和受限表达式曲线，允许自由组合。标注由平台排版，复用本地公式引擎。几何关系与受支持数值规则独立复核，不能把 JSON 合法当作科学正确。

V1 是静态教学示意图，不是任意题目的精确仿真。无关键条件、存在矛盾或不能核查关键关系时拒绘；布局假设不能变成新增物理条件。供应商接口只接收题目、取消信号和预算，未来可替换，正式用户界面不开放原始 SVG。

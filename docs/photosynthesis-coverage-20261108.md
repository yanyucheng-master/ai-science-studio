两个固定样例的正例为标准题、语义变体、分隔和顺序变体。反例包括缺项、冲突、越界、错误操作和范围外子问。路由实页另测报告性背景、并列及编号指代、普通概念模拟回退。课堂操作时间仍由教材流程定义，界面动画比例只定位步骤。

复现入口为 server 目录的 photosynthesis 与 leaf-disks 模型和浏览器脚本、verify-photosynthesis-routing-browser.js --intent、verify-photosynthesis-separators-browser.js，以及 verify-photosynthesis-learning-browser.js。学习脚本验证左右六步、播放越过步骤、预期和学生记录区分、0/10/非法、来源与可比性、刷新、收藏、分享和重置。具体执行 SHA、逐组退出码和可访问图随本轮送审报告附上。

学生记录仅保存在当前页的实验视图中。播放、定位、全屏和失败新题保留草稿，回退到观察之前暂时隐藏比较。重置、刷新、新实验、离开当前学科和从收藏或分享重新打开会清空。收藏按钮和复制链接本身保留本页草稿，收藏和链接只记录受检题目及原有实验配置。数据不进入分享协议、原题、导师请求、长期存储或定性模型。

高中记录只比较学生提供或假设的上浮计数。要求三组整数、同一正观察时长和条件可比。页面录入限制为 0.01–1440 分钟且最多两位小数，属于界面校验。模型始终没有预填的三组浮片数据，单片机理演示不能据此换算产氧量或速率。初中比较的是学生预测与冲洗完成后的教材预期。解释题的反馈依据教材定性关系。

# 教材实验与其他学科的所问范围

固定流程先对原题做完整严格解析。解析失败时，路由单独区分操作记录、问题标题和实际所问。题干中的卡片、讲义、实验记录等转述可以包含多条教材操作。背景段在问句、题目标题或新句处结束，逗号和分号可连接同一段背景。引文在路由中保留边界，内容只供识别真实子问的指代。所有实验参数和条件仍由原有解析器在完整原文中核对。

明确只问其他学科可以限定之前的无所问事实。有一个限定性所问且没有生物子问时，已有模板还须接受完整原文才可生成。无范围标记的成组教材操作仍是固定流程证据。教材条件和其他实验所问同时出现且归属未明时，页面要求明确范围或分开提交，保留原实验及播放状态并显示教材核对原因。引用操作的子问、共用一个动词的并列所问也参与这个判断。普通概念问答沿用现有回退。

这是一套有限的语句边界规则。跨句背景可以用明确的背景标签和题目标题分隔。只包含教材事实且无法确认所问时，页面仍可要求补充信息。其他模板照常核对完整题目，因此未经确认的多余数值或矛盾条件仍可能被拒绝。

在 `server` 目录运行 `npm run test:photosynthesis:intent` 可执行正常按钮矩阵。矩阵覆盖相关独立模板和联用模板、学段、导师有无和注册顺序。模拟失败与普通概念问答的模拟成功分别记录。模板 API 用例单列于 `test/biology-protocol-separators.test.js`，沿用上轮分隔符与顺序变体。

# 手机端布局与触控手感（2026-10-25）

用户在手机上实测后提出三个问题：点按钮出现很强的蓝色选中框；题目显示不全且“生成实验”按钮占位过大；竖屏一次塞进太多东西。本轮在不改实验计算与业务脚本的前提下重排手机竖屏，并修复触控手感和横屏全屏。用户授权全面改动，最终方向由用户审查调整。

## 范围与原则

- 手机布局只在 `max-width: 640px` 下生效；641px 以上（平板、电脑）保持原布局。宽屏唯一的行为变化：输入框按 Enter 直接生成实验。
- 触控手感规则按 `(hover: none)` 生效，不影响鼠标设备。
- 各实验画面内部（十几个物理模板、化学、数学、生物）只做通用处理：放大读数与结论文字、去掉一层嵌套边框、修个别遮挡；不逐个重做场景。
- 播放条仍在标题与题干之后、场景之前；参数仍在场景之后。沿用 10/22 的共享布局约定。

| `web/index.html` | 题目输入框 `input` 改为 `textarea`；“实验库”文字标签；字体改为不阻塞加载；`viewport-fit=cover`；引入上面两个新文件；styles.css 版本号 `20261025-mobile-1` |
| `web/styles.css` | 删除第一行阻塞渲染的 Google Fonts `@import`；3 处 `.prompt-input-wrap input` 选择器扩展为 `:is(input, textarea)` |

## 实现要点

- **蓝框**：原因是浏览器默认的点击高亮（`-webkit-tap-highlight-color`），全站从未设置。现设为透明，触屏下改用按下时 `scale(.96)` 与轻微变暗作为反馈。
- **悬停粘住**：52 条 `:hover` 只有 1 条限定了鼠标设备。触屏下对页首标志、导师标志、AI 入口、收藏按钮、思维链步骤的悬停位移与循环动画做了还原。
- **双击放大**：按钮、滑块等设 `touch-action: manipulation`。
- **输入框**：手机上 16px、默认 2 行、最多 5 行后框内滚动（iOS 小于 16px 聚焦会放大）。宽屏用 `wrap="off"` 加固定行高保持原单行外观（>900px 高 38px，641–900px 高 20px，与原 input 一致）。`mobile-shell.js` 拦截该元素的 `.value` 赋值来同步高度，因为 app.js 用赋值放入预设题。
- **输入区排布**：`.prompt-main` 改为网格，`.prompt-foot` 用 `display: contents`，学段移到标题右侧，学科四等分，输入框下方左“实验库”、右“生成实验”。手机上隐藏拍照、语音（只弹提示，没有实际功能）以及页首的学段按钮（避免两套同时出现）。
- **生成前**：实验卡用 `max-height: 0` 加 `visibility: hidden` 收起（保留宽度，避免场景按 0 宽度测量），隐藏空的思维链和导师卡；没有收藏时隐藏收藏卡（`:has`）。新增“快速开始”卡片：按当前学科与学段列出最多 6 个预设实验，点一下调用 `applyPhysicsPresetChoice` 后直接生成；更多时显示“全部 N 个”打开实验库。AI 即时示意图出现时隐藏快速开始。
- **实验卡**：标题独占一行；学段标签与收藏、分享同一行（`.experiment-heading`、`.title-row` 用 `display: contents` 后用网格排布）；题干默认 3 行，超出时显示“展开全文”。
- **播放条**：不改 `display`（静态模板靠各学科的 `display: none` 隐藏播放条，第一版改成 grid 时把它们误显示出来，已改回）；用 flex 排序加绝对定位把时间放到进度条下方。按钮 40–44px。
- **字号**：生成后各学科有 `body.subject-*-active:not(.awaiting-generation) …` 这类更具体的规则（如物理导师卡 9.5px），所以手机规则统一加 `:root body` 前缀，必要时用 `:root body:not(.awaiting-generation)`，依靠加载顺序在同级时胜出。
- **场景**：平抛、电路、通用物理的外层 lab 去掉边框与背景；平抛场景改为按内容高度展开（原先结论在 390 宽时就被裁掉 12px）；铁与硫酸铜的“反应完成度”移到读数面板下方。
- **全屏**：竖屏隐藏题干；横屏且高度 ≤500px 时改为左侧画面、右侧标题/播放条/参数（原先场景只剩约 80px 高）。高度用 `100dvh`，并考虑安全区。
- **底部快捷条**：输入区滑出屏幕且滑到思维链/导师卡时出现“换题 / 问导师”，在实验卡范围内不出现，避免挡住参数。AI 问答页、全屏、公告打开、演示模式下不出现。
- **字体**：改为 `media="print" onload` 的不阻塞加载；连不上 Google Fonts 时页面先用系统字体显示，不再等待超时。

## 验证（云端沙箱 Chromium，本地页面，所有外网请求拦截，未请求真实 AI）

- 25 个预设实验在 390 宽逐一生成：播放条显隐与改前一致；无横向溢出；场景内文字无新增裁切（平抛原有的裁切已消除）。
- 电脑与平板（1366、1024、820）改前改后整页截图逐像素对比：差异只在题目输入框那一行文字的亚像素位置，其余一致（电路电流点动画本身每次不同）。
- 手机端检查（首页与 8 类实验）：小于 12px 的可见文字只剩页首英文小字 11px，以及木板—滑块场景内的受力标注；可点控件的宽高均不小于 36px（主要按钮 40–44px）；控制台无错误；分享链接在手机上打开正常。

## 第二轮：真机反馈（2026-10-25）

用户在手机上实测线上版本后提出：快速开始的小字超出卡片边框；电路实验线条太粗，场景右上角的全屏按钮压住说明文字，建议把全屏按钮移到收藏、分享那一排并检查其他实验；手机取消小窗；生成实验等动画帧率低。

### 改动（只改 `web/mobile.css`、`web/mobile-shell.js`、`web/index.html` 版本号、`web/announcements.json`）

- **快速开始溢出**：卡片原来是 `button` 上的 flex 纵向排布，部分国产浏览器内核里不生效，说明小字按行内排版溢出。改为块级排布，卡片 `overflow: hidden` 兜底，公式片段在说明里改为行内以便省略号生效。
- **全屏按钮**：`mobile-shell.js` 在手机宽度把 `#fullscreenButton`（播放栏）和 `#sceneFullscreenButton`（场景右上角）移到 `.header-tools` 最前面，宽屏时放回原位。场景按钮的显隐沿用原有各学科规则；播放栏按钮跟随播放栏是否显示（脚本根据播放栏的计算样式给 body 加 `transport-visible`）。播放栏右侧只剩重置和倍速，时间标签位置随之调整。原先给角上按钮预留的空白一并收回：读数面板右侧、`.biology-stage` 顶部 50px、`week1-scene` 实验（并联电路、平面镜）顶部 50px、示意图缩放工具条右侧。
- **电路图**：线宽用 `vector-effect: non-scaling-stroke`，缩到手机宽度后仍是 4px，显得很粗。手机上导线、元件改为约 2.2px，电源长短线 1.6/4.6px；标注从细体 12.5–14.5（viewBox 单位）改为常规字重 21–22，约 8px；顶部电流方向说明左右撑满、居中两行，电路图下移让出位置。
- **其他实验检查**：25 个预设实验在 390 宽逐一截图。另修了木板—滑块受力/起点标注（8.5–9px → 11px）。修正第一轮的一个问题：给 `.generic-physics-lab` 加的 `inset` 对相对定位的化学、`week1-scene` 实验造成右移约 10px，已去掉。
- **小窗**：手机宽度隐藏“更多”里的“小窗”；从宽屏切到手机宽度时若正处于小窗，脚本自动点“全屏”改为整页问答。
- **动画卡顿**：触屏设备（`hover: none`）上去掉所有动画区域上的 `backdrop-filter`（卡片、场景读数面板与提示条、生成动画遮罩等），卡片背景改为 93% 不透明白色；生成动画去掉旋转的锥形渐变描边（遮罩每帧重绘）、标题流光与骨架条的 `background-position` 动画（改为透明度呼吸）、圆球 `border-radius` 变形、舞台与步骤文字的模糊过渡、一个大色块。

### 验证（沙箱 Chromium，触屏模拟 390×844、DPR 3、CPU 降速 4 倍，各 3 次取平均）

| 场景 | 改前 | 改后 |
| --- | --- | --- |
| 生成实验动画帧率 | 23.5 帧/秒（每 2.6 秒约 17 个长帧） | 48.7 帧/秒（约 2.7 个长帧） |
| 刹车实验播放帧率 | 40.9 帧/秒 | 47.4 帧/秒 |

这是桌面浏览器模拟，不能等同真机帧率，只用来比较改前改后。开屏动画两版都约 49 帧/秒，本轮未改。

- 共享布局验收 46/46；360×780、375×667、430×932 的可播放实验 18/18（全屏按钮移到标题区后，验收脚本点 `#fullscreenButton` 仍能进入和退出全屏）。
- 25 个实验：播放栏显隐与改前一致，无横向溢出，场景内无文字裁切；首页与 8 类实验小于 36px 的可点控件为 0。
- 电脑与平板（1366、1024、820）截图与改前一致（全屏按钮只在手机宽度移动，性能规则只对触屏生效）。

## 第三轮：遗留问题收尾（2026-10-25）

处理第二轮“仍待处理”中的前两项，以及第一轮遗留的 AI 导师内嵌头部问题。

### 改动

| 文件 | 改动 |
| --- | --- |
| `web/mobile-shell.js` | 平抛示意图手机取景；实验库列表打开时滚到可见 |
| `web/mobile.css` | 平抛场景高宽比与文字；内嵌导师头部两行；实验库列表最大高度 |
| `web/app.js` | 函数图标注自动选位（所有宽度生效） |
| `web/index.html` | app.js、mobile.css、mobile-shell.js 版本号改为 `20261025-mobile-3` |
| `web/announcements.json` | 新公告 `20261025-mobile-round3@1` |

- **平抛示意图**：原 SVG 固定 `viewBox="0 0 640 290"`，手机上缩到约 0.55 倍，内容只占中间一块。现在手机宽度下由脚本按 `#projectilePrediction`（预测轨迹）、`#projectilePlatform`、`#projectileHeightText` 的 `getBBox()` 加上水平速度箭头长度算出取景框，再把高宽比（限制在 1.05–2.4）写到 `--projectile-aspect`，`.projectile-world` 按这个比例取高度。轨迹或箭头的 `d` 改变（换参数）时重新取景；宽屏恢复原 `viewBox`。示意图文字 16（viewBox 单位），高度标注 14，避免压到平台。
- **函数图标注**：`renderTemplateGraph` 原先按固定候选位置放直线名称，只避开别的标注，不看直线本身，所以二元一次方程组里“① 2x + y = 5”会压在另一条直线和交点标注上。新增 `placeMathLabels`：收集直线、曲线（`path.math-curve` 折线段）和坐标轴线段，标注候选框用 Liang–Barsky 判断是否与线段相交；依次按“避开图线和坐标轴 → 只避开图线 → 只避开其他标注”三档尝试，仍放不下就不显示。说明框（`#mathSlopeNote`）也作为障碍。直线名称、函数名、交点各增加若干候选位置（交点按 18/28/40 半径 × 12 个方向）。公式排版（`ScienceFormula.enhance`）在测量前同步执行，否则测到的是排版前的宽度。电脑端也走这套逻辑。
- **内嵌导师头部**：手机上原来是头像一行、按钮一行、会话工具一行，且对齐不一。现在第一行左侧头像（36px）、右侧“更多”和关闭（40px）；第二行会话工具栏（题目、新对话 36px，提示优先标签 36px/12px，回答模式下拉 36px）。只作用于内嵌状态，整页问答不变。
- **实验库列表**（回归测试发现，第一轮引入）：手机上列表排在输入框下方，`verify-week2-browser.js` 在 390×844 打开时列表底部超出屏幕。现在列表从关闭变为打开时，若伸出屏幕底部，立即（不用平滑滚动）滚到完整可见；最大高度改为 `min(460px, 100dvh - 96px)`。快速开始的“全部 N 个”也走这条逻辑，不再滚到输入区顶部。

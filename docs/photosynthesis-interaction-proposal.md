# 两个固定教材样例的互动闭环方案（2026-11-05，待审查）

对应[第七项审查](https://github.com/yanyucheng-master/ai-science-studio/issues/9#issuecomment-6624372680)。本轮先修复安全、识别和播放器缺陷。本文件是产品方案，不把尚未实现的控件写成完成，不代本人确认20个题型族整体方案。

## 已实现与缺口

目前提供教材固定步骤、统一播放和步骤开头回看、教材预期/机理解释、题目/收藏/分享及原题和当前步骤的导师上下文。初中冲洗完成前不显示最终蓝色；高中记录表始终待观察，单片机理不代表三组实测。

学生预测录入、观察记录输入、预测与观察对照、解释反馈尚未实现，因此当前不是完整“预测→操作→比较→解释”闭环，不以修好播放器宣称该要求完成。

## 最小初中方案

- 预测：操作前分别选择见光区与遮光区完成检验后的现象，明确标“我的预测”，可留空。
- 操作：仍为人教七下正文29–30页六步和同一播放器，不增加光强、浴温、产量或动力学参数。
- 比较：第6步冲洗完成后，才把个人预测与“教材预期：原见光区蓝、原遮光区不变蓝”并列；不把预测说成实际观察数据。
- 解释：选择同叶对照变量及暗处理、水浴、漂洗与滴碘的目的；本地反馈只解释教材定性关系，不输出淀粉质量或氧气体积。

教材内容不变。预测控件是网页教学组织建议，不声称原教材有相同控件；不增加J02其他变式或J03实验。

## 最小高中方案

- 预测：可选输入现象预测，不预置“强光必然最多”的正确排名，也可不回答。
- 操作：保留人教必修1正文105页参考流程：0.6cm直径、30片分3组各10片、排气/暗处待用、富CO2清水、5W灯及米尺、同一时段和其他条件可比。
- 记录：只接收学生自行提供的同一观察时段的三组计数，每组整数0–10片。标明“学生提供，网页未经实测核验”，并区分课堂观察与自行假设；不预填或补缺组数据。
- 比较与解释：只比较已给计数及与预测的差异，不从灯功率/距离、浮片数或动画推算光合速率、总产氧量、糖量或动力学；不强行把相关性解释成确定因果。

额外学习记录不改变原来的无数据模型，原observedCounts仍为三个null。超界、非整数、缺来源或条件不一致时保留草稿并给具体提示，不夹值或补齐。

## 需协调的产品边界

预测和记录控件超出原来的固定步骤回看实现，本轮先列方案，尚未实施。需要先确定：记录仅限本页还是需刷新恢复；重置是否清除记录；分享/收藏是否携带额外学习数据。

最小建议为本页临时学习记录，和原题、固定模式、播放状态分离。分享继续只恢复受检教材流程，界面明确记录不随链接传递。若要求带记录分享或恢复，应单独审查来源、校验和协议边界；不把记录暗塞进share-v1、原题或后端，不放宽本轮解析器去接受任意实测数据。

方案对应的产品选择核对后再实施。开发侧届时负责0/10/非法值、空数据、条件/来源冲突、预测与教材预期/学生记录的区分、重置/保存/分享、对应初高中讲法、360/390/820/1366与横屏/全屏/触控及完整适用回归。保持两个样例的数量和教学范围，不扩展其他题型。
